Agent 365

The governance control plane — "E5 but for agents" — but GA shipped with key capabilities still in preview

AnnouncedIgnite 2025; GA May 1, 2026
Pricing$15/user/month standalone; included in M365 E7 Frontier Suite ($99/user/month)
What's GAOn-Behalf-Of (OBO) agent governance — agents acting on a licensed human's delegated token

Notes from the Field
🔴 Scout is not purchasable
There is no SKU for Scout. If stakeholders ask for "the Build 2026 agent," the answer is: Frontier-only desktop preview, two separate license prereqs, no pricing, GA not before October 2026.
⚠️ Agent 365 GA ≠ autonomous agents
The May 1 GA covers On-Behalf-Of governance only. True autonomous agent identities with their own credentials remain in preview. "Every agent gets an Entra ID" describes an aspiration, not what's available in production today.
📋 Copilot Studio is the only fully GA path
For practitioners building or governing autonomous agents today, Copilot Studio agents are the only fully GA and purchasable option. Build policy around autonomous trigger costs before provisioning agents in production environments.
🔴 OpenClaw on endpoints is a governance event
Scout's OpenClaw foundation means the runtime is arriving on managed Windows devices. Microsoft's own Defender guidance treats OpenClaw as untrusted code execution with persistent credentials. Govern before Scout forces the question.
⚠️ "Autopilot" is a marketing category, not a product tier
Introduced at Build 2026 with Scout as the only member, "Autopilot" has no relationship to Copilot Studio autonomous agents, Agent 365, or Copilot Cowork in Microsoft's published product taxonomy. It is not a purchasable category.
📋 Project Opal is the sleeper
Opal's cloud-sandboxed Windows 365 for Agents architecture is the most technically coherent implementation of computer-use for enterprise tasks. It received minimal Build airtime but is the most governable of the three computer-use surfaces.
