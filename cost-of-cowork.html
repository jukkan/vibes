01

Three AI products, three licensing models

Work that looks identical to the end user is now priced three completely different ways. I'd expect nothing less from Microsoft.

Pay once, per seat

Microsoft 365 Copilot

$30 / user / month

Researcher, Analyst, in-app Word/Excel/PowerPoint/Outlook/Teams agents and extensibility are included. The expensive reasoning is hidden inside the seat. Marginal cost per run ≈ $0.

Pay per task · metered

Copilot Cowork

seat + Copilot Credits

A cloud-hosted agent that runs long, multi-tool jobs end to end. You pay for the whole orchestration package — not just tokens. PayGo is $0.01/credit; off by default for a reason.

Pay per token · GitHub meter

Microsoft Scout

seat + GitHub Copilot

OpenClaw-based desktop "Autopilot," Frontier-gated preview. No standalone rate card — its marginal cost rides on GitHub AI Credits (also $0.01/credit), which got pricier on 1 June.

05

So where should the work go?

IMO — tied to cost, governance and speed-to-value, not vendor enthusiasm.

Default · cheapest place to think

Stay in M365 Copilot

If the job is "research it, summarize it, turn it into a doc/workbook/deck, let me edit" — that's already in the $30 seat via Researcher, Analyst and the Office agents. Microsoft is swallowing expensive reasoning here. Don't pay a meter for it.

Replace "help me" with "go do it"

Reach for Cowork

Justified when you genuinely value unattended runtime, multi-tool coordination, scheduling and long follow-through across M365. Turn it on deliberately, with tenant/group/user limits, alerts and a budget — not as the default deck-maker.

When you're ready for OpenClaw

Consider Scout (preview)

Compelling only when you specifically need local files + browser control + workspace autonomy + M365 context in one always-on agent. Heavier entitlement stack, experimental, and the cost rides on GitHub's now-pricier token meter. Power-user territory.

When you want predictable budget

Look outside Microsoft too

Claude Cowork is bundled into Claude Pro ($20/mo), Max ($100+/mo) and Team — "use it until you hit the wall." Great for budget control, bad for transparency. Honest caveat: hidden-behind-quota ≠ free. Microsoft claims Cowork is 30–40% cheaper than Claude Cowork in its own M365-connected tests.

06

Caveats & how to verify

When it comes to AI, licensing stops being an exact science (as if it ever was). These are the main information sources and confidence levels used in this analysis.

  • HighCowork is GA & metered. $0.01/credit PayGo; $200/tenant/month for a 25,000-credit capacity pack ($0.008); P3 pre-purchase for tiered discounts. Verify in the M365 admin center → Billing, and the Copilot Credits Learn doc.
  • MediumThe $120–$410/user/mo figure is Microsoft's own default assumption, not a guarantee. It's the math baked into the estimator's Frontier-usage defaults. Your actual per-task credits depend on model, retrieval, tool calls and runtime — and the 'Cowork 1' (cheaper, Azure-hosted model) is "coming soon."
  • LowScout pricing is inferred. Microsoft published no Scout meter; the numbers here treat it as GitHub Copilot AI-credit consumption. Scout is Frontier-gated preview (Intune policy + attestation + GitHub Copilot Business/Enterprise). Treat as directional.
  • HighGitHub Copilot is now usage-based (since 1 June 2026). 1 AI credit = $0.01; Business $19/1,900 credits, Enterprise $39/3,900 (promo 3,000/7,000 until 1 Sep 2026); no fallback to a cheaper model when the budget runs dry. Verify on docs.github.com.
  • MediumClaude plan pricing changes often. Confirm current Pro/Max/Team/Enterprise tiers and usage limits on anthropic.com/pricing before quoting them to anyone.
